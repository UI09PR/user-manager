# User Manager  

Этот проект можно запустить двумя способами:  
- С использованием **Docker**
- Без использования **Docker**

## 1. Подготовка  

Перед запуском проекта необходимо создать и настроить файл окружения `.env`.  

1. **Создайте файл `.env`** на основе `env.example`

## 2. Запуск 

1. Выполните команду `npm install`;

2. Выполните команду `npm run dev:server`;

3. Выполните команду `npm run dev`;
